# 《于世界之门前》
**《Before the Gate of the World》**

### 超越凡俗

**力量（力）、体质（体）、反应（敏）**统称为“素质三项”，是战士考核的主要部分；

**智慧（智）、意志（信）、感知（感）**属于“精神三项”；

**位格（命）、亲和（道）、魅力（魅）**则归为“神秘三项”。

#### **素质三项**

**力量**表征身体爆发力，是“力”与“速”最直接的体现。该属性越高，其外在表现就越强。

**体质**衡量身体的综合素质，尤其偏向于“抗性”。体质越强，物理与魔法的综合防御能力就越出色，同时也涵盖了自愈能力与异常状态的抵抗力。

**反应**决定身体的敏捷与协调性。即使像食人魔这类力量强大、冲锋迅猛、皮糙肉厚的生物，也常因反应迟缓而显得笨重。此项能力直接关乎闪避、精准与动作效率。

以上三项作为身体素质的核心评判标准，是相对容易通过锻炼提升的基础属性。战士系职业普遍依赖它们，而像狂战士、刺客等不同分支，则会在三项属性的侧重上产生分化。

因此，**“素质三项”** 的最终数值由两个部分构成：**种族等级**：基于种族基准值，再加上个体先天差异（即天赋）的调整。**职业等级**：代表通过后天系统性的锻炼与实战所获得的成长。

#### **精神三项**

**智慧**主要指先天的智力水平与逻辑潜能。此项属性在种族基准值上趋于稳定，虽能通过长期教育与学习获得有限增长，但最快的提升期仍集中于幼儿至成年的生理发育阶段。它是法师职业最重要的属性。

**意志**意味着坚定的内心，可以表现为全面的“毅力”，也可以是对于某项准则（无论正邪）的执着坚守。它也被视作精神层面的抗性，但意志坚定者未必不懂变通。此品质常受神明青睐，是成为牧师或者战士的理想资质。

**感知**是精神的触角，是凡俗躯体用以捕捉世界细微振动的敏锐感官。它可以被理解成简单的“看见”或“听见”，也可以是不来自身体素质的一种将破碎信息拼合成完整图景、从平静表象下嗅出暗流的内在洞察力。高感知的个体，能听见他人心跳中隐藏的紧张，能捕捉对手肌肉纤维即将发力前的微兆，能从风中品出远山之外火种的气息，同时也表现为一种近乎先知先觉的预判能力。是刺客、游侠的资质。

**精神**属性一旦稳定便难以大幅变动。研究表明，越是智慧种族，个体间的精神属性差异越大；反之，越原始的族群则越趋于统一。提升途径包括学习、外物辅助，或是在人生重大变故中的“醒悟”与磨难中的“坚定”，但这些方式无不代价昂贵且可遇不可求。

#### **神秘三项**

**位格**一种玄奥的概念，目前被学界暂定义为个体的“存在价值”或对“命运线”的影响力。其变化规律至今未被透彻解析：它可能随其他属性的成长而跃迁，也可能因社会地位的改变而浮动，但有时又毫无变化。由于它在神秘学，尤其是在炼金与仪式“等价交换”原则中的核心地位已被反复证实，故而被确立为一项关键属性。

**亲和**代表个体的思想境界与思维方式。亲和高的人更易超脱自我，与环境乃至万物共鸣——无论是自然变迁还是群体情绪。需注意与“魅力”区分：共情能力强，不代表处世圆滑或善于交际。此属性本身不与善恶划等号，但普遍观测到善良个体中亲和偏高者更多。自然意志与部分神祇偏爱此特质，适合成为德鲁伊。

**魅力**此项属性较为直观，涵盖了从外貌到言谈等一系列能够吸引他者的能力。它可以通过后天学习提升，但魅力本身也是一种天赋——有些人能轻易掌握取悦他人的技巧，有些人则只会弄巧成拙。魅力的作用对象并不限于人，它更体现为一种通用的“情商”，即能否快速学习并适应特定情境，并灵活调整自身以产生吸引力的综合能力。

### 阵营划分

阵营，源于最初那些决定力量性质的“超凡道途”。每个人所选择的道路，即定义了他的“阵营”；从另一角度看，这也是一种性格总结与价值观归纳。

在超凡道途演化成超凡职业之后，道途背后所代表的阵营则没有消失，而是沿顺到了日常的评判当中，现在虽然一般不再与职业相关，但也有一些超凡职业或者能力会要求阵营，一般来说其实就是力量赐予者（例如神明）对其追随者的阵营偏好、某些依赖特定行为或特定仪式来完成晋升的超凡路径，其本身就需要内在信念与外在行为的高度统一。

阵营可以被归纳为最简单的九宫格：【善良、邪恶、中立】*【绝对、混乱、守序】。但是当然，存在一些更细节的划分，比如可能存在双相、抉择偏向、特异底线之类的。
