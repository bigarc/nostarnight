# 贡献指南
欢迎加入「无星之夜与救世英雄传说」的共创！

## 一、贡献流程
1. Fork 本仓库
2. 创建分支（命名规范见下）
3. 修改内容
4. 发起 Pull Request
5. 等待审核

**所有贡献者在提交 PR 时，即表示已阅读并同意本项目的 [CLA](./CLA.md)。**

## 二、推荐创作内容
基于已完善规则的内容如
- 完善种族内容
- 新建子种族
- 完善能力内容
- 新建超凡子职业、超凡子能力
- 完善势力内容
- 新建子势力
- 新建人物、装备、物品
- 新建自然、城市、风俗、其它局内人叙事作品
- 自定义棋子开牌（战棋部分）
- 添加词库与字库、翻译内容

## 三、不建议但不是不能的内容
以下内容**不建议随意修改**。不是不允许，而是审核更严格、影响范围更大：
- **关键历史事件**：如「黑铁时代终结」「命运女神降临」「魔界坠落」
- **核心人物**：如「玛利亚·希伦特」的身份、性格、结局
- **核心设定规则**：如「泡世界」的运作逻辑、「具现标识」的原理
- **世界底层逻辑**：历法、神系、魔法体系的基础规则

**贡献方式**：
1. 先讨论，说明你想改什么、为什么改、会影响哪些已有设定。
2. 达成共识后，再发 PR，并额外标注修改内容

# Contributing Guide

Welcome to co-create *Nostarnight and the Legend of the Savior Hero*!
## 1. Contribution Process
- Fork this repository
- Create a branch (naming conventions below)
- Make your changes
- Open a Pull Request
- Wait for review

**All contributors, by submitting a PR, confirm that they have read and agreed to this project's CLA.**

## 2. Recommended Content

Content based on established rules, such as:
- Expanding race content
- Creating new sub-races
- Expanding ability content
- Creating new supernatural sub-classes and supernatural sub-abilities
- Expanding faction content
- Creating new sub-factions
- Creating new characters, equipment, and items
- Creating new nature, cities, customs, and other in-universe narrative works
- Custom piece cards (war-game portion)
- Adding glossary and lexicon entries, translation content
## 3. Discouraged but Not Forbidden Content

The following content is not recommended for casual modification. It is not forbidden, but review is stricter and the impact is larger:
- Key historical events: such as "End of the Black Iron Age," "Descent of the Goddess of Fate," "Fall of the Demon Realm"
- Core characters: such as the identity, personality, and ending of "Maria Sirent"
- Core setting rules: such as the operating logic of "Bubble Worlds," the principles of "Manifestation Sigils"
- World foundational logic: calendars, pantheon, basic rules of the magic system

**How to contribute:**
- Discuss first: explain what you want to change, why, and which existing settings will be affected.
- After reaching consensus, submit a PR and additionally mark the changes.
