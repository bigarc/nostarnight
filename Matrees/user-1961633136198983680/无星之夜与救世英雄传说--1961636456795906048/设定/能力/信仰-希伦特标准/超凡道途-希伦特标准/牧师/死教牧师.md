# 死教牧师



作者：帝国外务部大主教

崇死教会的牧师们，按能力分主要为雕塑师、送葬人、赴死者三种 雕塑师是教会中的工匠与筑垒者。他们以虔诚的技艺雕琢圣像，并为纯净的灵魂提供栖息的圣所。石像鬼与圣棺的题材随思想的开放也在不断扩展 送葬人是教会最常现身于世俗的仆人。他们行走于城乡荒野，主持葬仪，安抚游魂，并以对不死造物特化的法术，专业而高效地执行净化——直接解放被束缚未前往地脉的灵魂——不生效即不亵渎 赴死者是更通用的牧师与战士——他们之后也可以选择成为专职的战斗人员——比如崇死圣武士，掌握着精悍的战斗法术与战斗技巧，比起温和且平民化的送葬人，他们更加“显眼”——他们同时也是石像鬼或者圣棺中灵魂的献身者
