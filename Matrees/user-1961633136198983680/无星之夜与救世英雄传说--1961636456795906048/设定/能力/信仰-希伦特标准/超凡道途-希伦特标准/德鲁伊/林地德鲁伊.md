# 林地德鲁伊



作者：帝国外务部大主教

林地德鲁伊是最广为认知的德鲁伊——包括了他们化兽的能力（虽然这并不算是林地德鲁伊专属的能力）、宁静安逸的性格、位于深林的居所与操控树木植物的能力。 林地德鲁伊几乎也可以算是自然之神的信徒，除了抽象的自然意志，他们还崇拜着作为自然之神的人神——称其为”人之母“或者“橡树之母” 对于诸神之间的秘事与人族的过往末梢，古代德鲁伊始终守口如瓶。但他们未曾想到—— 竟然有一位真神作为亲历者愿意细心解答娓娓道来，我幸运且荣幸。
