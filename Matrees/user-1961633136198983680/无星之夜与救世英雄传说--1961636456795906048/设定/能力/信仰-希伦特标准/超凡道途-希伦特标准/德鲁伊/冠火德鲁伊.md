# 冠火德鲁伊



作者：帝国外务部大主教

冠火德鲁伊是火山的崇拜者，也是德鲁伊中格外特殊的一支。他们并不避讳火焰，反而热衷于驾驭那份爆裂而原始的力量，性格也往往如火山般澎湃外放，豪迈且充满侵略性——如同火山本身，既带来毁灭，也带来肥沃的土壤。 他们的特色在于掌握着独特的原始火焰法术，尤其是涌动而不稳定的熔岩术法。这类法术威力巨大，却也较为笨重，充满力量感与不可控的威严。 正如火山同时意味着恐惧与肥沃，冠火德鲁伊也承载着这样的双重性：他们守护自然不被篡改的同时也是为饥民焚林拓荒的改造者。
