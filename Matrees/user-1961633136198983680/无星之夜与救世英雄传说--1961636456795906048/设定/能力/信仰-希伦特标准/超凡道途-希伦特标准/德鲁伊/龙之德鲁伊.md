# 龙之德鲁伊



作者：帝国外务部大主教

龙之德鲁伊将目光投向了超越一般自然意象的存在——更准确地说，他们所崇敬的是生命本身的宏伟力量，而龙作为这股力量最强大的具现，自然成为这群“拜兽”德鲁伊最显著的象征。 这并非指涉寻常的兽崇拜。若回顾命运女神所述的神代历史，其中人与兽族战争的篇章，便可知“拜龙”与“拜兽神”之间，实则仅有一线之隔。 不过，既然这个群体自古便由一位真正的远古龙巫妖亲自引导与见证，其道路应当不致偏离。 但听说野性教会内部存在一些矛盾，反倒是那些年轻的看不清。
