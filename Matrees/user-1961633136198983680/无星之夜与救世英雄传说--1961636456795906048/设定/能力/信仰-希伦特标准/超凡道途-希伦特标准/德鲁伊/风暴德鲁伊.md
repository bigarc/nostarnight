# 风暴德鲁伊



作者：帝国外务部大主教

风暴德鲁伊是自然风暴的崇拜者，他们信奉风暴那纯粹而癫狂的力量，并以“随风而动、随风而行”为自身准则。 此处所指的风暴，乃是纯粹的自然伟力，而非由风暴之神所化用的“启明星”象征。二者意象迥异：一者源于天地，一者源于信仰。 除了自身所受祝的自然之力外，风暴德鲁伊还掌握着强大的风暴巫术。这是一种基于原始仪式的法术，须通过繁复而精准的仪式发动，但其威能也极为可怖且持久，常能长时间改变天象与环境，被视为现代禁咒与长效环境塑造类法术的雏形。
