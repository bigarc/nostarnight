# 桂芙柅的银月桂冠



作者：帝国外务部大主教

在厄尔辛，骑士们普遍尊奉”月神桂芙柅“（被认为是正义女神变体），但唯有那些最为忠贞、坚定的骑士，才能成为神明亲选的圣武士。他们被称为“银月桂冠”，既是月神的圣武士，也是骑士阶级中的至诚者。 这些圣武士沿袭着骑士的晋升体系——自新月至月冠，逐级而上。与寻常骑士不同的是，他们额外被授予一顶象征月神直接眷顾的银色桂冠与月光剑。 他们的装备则与同阶骑士保持一致：若出身于本地狼人氏族，则披挂结合变形特征的狼骑铠；若来自外来人族，则基本穿戴希伦特风格的银骑士甲胄。
