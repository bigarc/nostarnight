# 亥里厄的崇死圣骑



作者：帝国外务部大主教

负馆骑士数量稀少，却异常强大。在其他教会可由战斗牧师代行武职之处，崇死教会将全部神圣权能凝聚于这少数誓言者之身。 然其代价亦极为沉重。那身精美如纪念丰碑的大理石雕饰重甲与随行棺椁，不过是表象；真正的代价，是至亲永逝的伤痕。更多心碎者止步于成为淡泊的雕塑师，唯有极少数能将这份伤痛淬炼为更沉重的誓言。 因此，多数负馆骑士并非出身教会，而是于此寻得慰藉的伤痛之人。雕塑大师将圣像与天使刻入其甲胄——比受祝圣的石像鬼更虔诚；将逝者面容蒙纱浮刻于棺椁之上——比任何魔影留痕更精确。甲胄即是一座移动的圣坛，棺椁即是一具具活的思念。 他们因此向已逝的死亡之神立誓，守护所有逝者的永恒安眠。
