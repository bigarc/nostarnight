# 自由之渊洋骑士



作者：帝国外务部大主教

渊洋教会的圣骑士其实很难说是标准意义上的圣武士——这是一个新兴的教会。 如果说风暴牧师、风暴圣骑是海上的导航者，那么渊洋骑士便是海上的船长 新生的水神也并未实际赐予下什么力量，“船长”们还要依靠自身——在海上，主要依靠的是理智、知识与勇气。
