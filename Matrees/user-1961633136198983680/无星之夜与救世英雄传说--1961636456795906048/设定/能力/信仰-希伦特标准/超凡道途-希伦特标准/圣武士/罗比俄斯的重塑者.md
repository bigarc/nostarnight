# 罗比俄斯的重塑者



作者：帝国外务部大主教

重塑教会的圣武士同样被认为不以武力见长，他们更将超凡的医术奉为至高的使命。他们不着重甲，仅以简朴的布带裹身，形似寻常教徒，却掌握着接肢续体、血肉重塑等非凡技艺。 但比起和善牧师，圣武士们确实要承担暴力的职责，他们是医师的忠诚的护卫，并自愿献身承担血肉改造。 在重塑教会中，这些追随大医师的圣武士并不会夸耀自己的荣誉与职责，他们默默跟随守护对象，并以其为主体行动。所以一般一位重塑誓言的圣武士并不会随意单独出现。
