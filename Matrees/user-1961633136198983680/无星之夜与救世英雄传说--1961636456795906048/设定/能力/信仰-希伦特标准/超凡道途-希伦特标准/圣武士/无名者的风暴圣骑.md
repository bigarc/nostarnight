# 无名者的风暴圣骑



作者：帝国外务部大主教

荣耀归于风暴，忠诚至死不渝。 风暴之神值得尊敬，风暴的圣武士们同样值得尊敬。除了现代的航路，不灭的启明星同样在黑暗时代抚慰了无数人心。 曾经，风暴之神被称为是与人间最近的神明（当然现在已经换神了）但航标永远指引着人类，指引着这些如今属于海洋、属于航路、属于商贸与契约的圣武士。 风暴圣武士大多穿戴蓝白相间的服装，并佩戴或者在其上绣制象征启明星的银质徽章。提灯、长枪、链剑、刃盾是他们标志与擅长的武器。 现在的他们是“斤斤计较”的高手，是商业裁判官与海上导航者，他们乐于为被蒙蔽的人澄清欺诈
