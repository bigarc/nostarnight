# 圣特里亚的惩戒圣骑



作者：帝国外务部大主教

惩戒圣骑士即信仰正义的圣武士，他们是绝对的秩序善良或者秩序中立（由或许是秩序邪恶（笑））他们有个更广为流传的名字——审判官——完全由正义教会秘密地自行培训，一个已任职审判官也几乎无法脱离教会 他们是正义女神的银之臂——这来自于神赐武装，他们身着黑袍，佩戴银色的臂甲和制式胸甲。善使大剑——他们的黑色破魔双手剑同样是神赐的武装。 正义女神要求他们惩治邪恶、驱逐邪异；保卫”人“的荣光与生命——不惜代价
