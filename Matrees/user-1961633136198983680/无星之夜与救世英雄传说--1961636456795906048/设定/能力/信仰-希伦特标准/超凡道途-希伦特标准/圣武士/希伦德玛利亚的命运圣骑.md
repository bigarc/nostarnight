# 希伦德玛利亚的命运圣骑



作者：帝国外务部大主教

命运骑士一般身着素白甲胄，形制简朴，不加雕饰。这既因圣武士之道不重外物，也因命运教会本身并未设立成建制的圣骑士团。因此，命运圣骑大多不是由教会统一培养，他们或是考核后受聘进入教会体系，成为帝国治理结构中的一员（届时或会配发制式的“治安官甲”），抑或自行以冒险者的身份行走于世，以自我要求替神明管制世间。在希伦特，他们常被视为最契合传统印象的“圣武士”。 希伦特要求他们明察是非，不妄下论断；并以道德准则约束己身，以法律规则安定他人。 惟愿公平如大水滚滚，使公义如江河滔滔。
