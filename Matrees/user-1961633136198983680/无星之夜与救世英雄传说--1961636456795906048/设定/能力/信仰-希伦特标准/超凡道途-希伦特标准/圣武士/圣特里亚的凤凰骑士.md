# 圣特里亚的凤凰骑士



作者：帝国外务部大主教

凤凰誓言隶属于正义教会，是惩戒骑士体系中的一个特殊分支。他们秉持着更为炽热的怒火与净化之焰，若不细察其徽记与渊源，外在确与寻常惩戒圣武士难以区分。 这一誓言的根源深植于精灵的古老传说——因此，一位凤凰圣武士往往首先是一位信仰正义女神的精灵。他们的银之臂甲与漆黑剑刃上，铭刻着展翅的凤凰雕纹；这正是因为正义女神在精灵的万神殿中，亦被视凤凰女神与战神。 精灵中的狂热信徒坚信，凤凰必将自灰烬中浴火重生。追随此誓言的圣武士亦将在战斗与牺牲后寻求赎罪与新生。
