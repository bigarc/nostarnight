# 流浪武者



作者：帝国外务部大主教

东方的土地已然在世界碰撞中被魔界所倾轧毁灭，现在仍旧能看到处于污染中的残影。这些风格奇异的城镇与建筑废墟，是曾与希伦特并肩过的古代城邦。异乡的武士也只得流落世界各处，但他们无时无刻不思念与怀念远方的家。武士这一道途也同样基本独属于这些异乡人，他们是如今稀少的“木”亚人——或者说“木精灵”。使用着薄而纤细的刀，比起战士也许更像是刺客，但他们传承着相同的战士精神——并聚焦于对武艺巅峰与精神境界的求索。现在？在面对魔族时，也许也带有殉道者的精神。
