# 恩斯罗巴之狂猎



作者：帝国外务部大主教

狂猎是最为独特的一支深林猎手，他们是一群战士，是使用利爪与投矛的猎人。并且以狂猎的恩斯罗巴为象征，一个深林猎手也必须在该雨林中完成指定的狩猎仪式，才能真正获得其认可，成为一名狂猎。
