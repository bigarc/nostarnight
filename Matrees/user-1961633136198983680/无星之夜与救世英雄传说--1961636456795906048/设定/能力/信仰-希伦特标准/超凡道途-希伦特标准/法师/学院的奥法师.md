# 学院的奥法师



作者：帝国外务部大主教

奥法师专注于魔法的现实具现，火球术、闪电链、冰风暴便是这些法师最为著名的法术，现代奥法师的研究方向则也是聚焦到了法术的能量转化方面，笔者也在持续关注奥法师们对于幽影界隧洞穿孔效应的研究。 还有一批更加独特的奥法师已经独立出来专注于研究法术之间的嵌合与相互作用，还有在实体机械与自动化方面的应用，现在他们被称为魔动术士。
