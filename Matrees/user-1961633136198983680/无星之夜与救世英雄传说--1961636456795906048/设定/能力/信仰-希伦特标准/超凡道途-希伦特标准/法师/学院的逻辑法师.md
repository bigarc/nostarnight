# 学院的逻辑法师



作者：帝国外务部大主教

逻辑法师同样并非新兴学派，其前身是长期钻研傀儡、控灵等领域的法师。他们早已将“创生”视为终极目标，并在该方向上积累了深厚底蕴。逻辑理论的横空出世，为这一领域带来了颠覆性的革命——一套切实可行的全新方法论，吸引了无数天才法师投身其中。 逻辑学派被认为是现代三大法术学派中最深奥、同样也是前景最广阔的一支，被誉为“魔法的未来”。 最终，在魔法学院内，遵循大魔导师斯卡蒂·斯卡哈的”旨意“，各相关分支被整合重组，共同构成了一个庞大而统一的综合性学派，名称则同样为多尼雷的舶来品。
