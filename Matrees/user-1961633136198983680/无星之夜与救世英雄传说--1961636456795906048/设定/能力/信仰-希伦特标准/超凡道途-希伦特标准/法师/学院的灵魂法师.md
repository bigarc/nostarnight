# 学院的灵魂法师



作者：帝国外务部大主教

死灵法术的终极目标——完美的复活，曾是无数学者的梦想，但这几乎等同于直接违逆世界的根本法则。无人成功（至少在过去是如此）。传统的亡灵法术，实则是截留灵魂在沉降或飞升过程中的残响，或仅是重新激起尸骸残存的生物反应。，因此，自古以来，亡灵法师都被视为亵渎者，而且根据原理，同一目的又可细分为多个流派，不清不楚地擅动很可能会招致死亡教会的惩戒，也可能引来重塑教会的劝导。 时至现代，这一领域的学者多以“灵魂法师”为正式称谓，其研究主要聚焦于灵魂的本质与死亡的边界。然而，这依然是一个近乎停滞的“死学派”——毕竟真神无私问询，冥界真实存在。 颇具讽刺意味的是，逻辑法师们已经开始尝试复现”人工智能“。
