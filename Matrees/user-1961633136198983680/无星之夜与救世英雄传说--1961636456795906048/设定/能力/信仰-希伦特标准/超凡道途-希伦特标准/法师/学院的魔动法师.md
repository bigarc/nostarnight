# 学院的魔动法师



作者：帝国外务部大主教

一个独特的新法师学派群体，从曾经的奥法师中独立而出，名称取自高等精灵的魔法动力、魔法机械。 他们专注于研究魔法之间的嵌合和与现实物体的物理互动。 一个巴卡洛夫的得意门生曾和我展示过——他使用圆盘法阵直接将一张白纸传送到我们面前，使用多个法术推动套组折叠纸张为一个蝴蝶，最后书写了蝴蝶翩翩起舞的逻辑阵列——最后自嘲叠蝴蝶的那一步在三个学派中最简单。
