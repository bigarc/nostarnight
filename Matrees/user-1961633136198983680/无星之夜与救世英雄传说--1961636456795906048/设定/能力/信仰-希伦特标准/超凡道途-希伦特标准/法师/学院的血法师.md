# 学院的血法师



作者：帝国外务部大主教

血脉术士是法师中以 “血脉” 为研究核心的学派。他们专注于追溯与重现传说中“天授者”的力量源头，探索魔法能力在种族与个体间的传承与表达。 其研究者大多自身便是具有天赋施法能力的血脉者——出于对自身来源的好奇、对血脉能力的关切，他们很自然地将学术重心置于血脉与施法天赋之间的关联之上。
