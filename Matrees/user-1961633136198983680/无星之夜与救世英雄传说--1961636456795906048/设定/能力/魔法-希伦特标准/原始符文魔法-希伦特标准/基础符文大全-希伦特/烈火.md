# 烈火



作者：帝国外务部大主教

最原始的火焰魔法形态-类似【火焰环绕】的表现形式 在成功释放时，会以符文为起点朝指定方向产生火焰，根据魔力量决定速度与范围，扩散过程中还可根据精神力指定方向以及选择转变为环形、蛇形、球形等。连带效果包括释放者轻微精神振奋、加速、目标爆燃（必定燃烧） 可戏法启用 范围：1/单位
