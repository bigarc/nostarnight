# 壳蛭



作者：帝国外务部大主教

自魔界随魔族迁徙出的掠食性“史莱姆”，但实际是一种魔界独特的共生生物。主世界早期文献称其为“猩流史莱姆”或俗称”血史莱姆“，后发现其具有共生能力，相关学家再依照魔界资料改称“壳蛭共生体”。民间仍混用两个称呼。是一种半智慧共生种族。被发现已经拥有了同希伦特人“共生”的能力
