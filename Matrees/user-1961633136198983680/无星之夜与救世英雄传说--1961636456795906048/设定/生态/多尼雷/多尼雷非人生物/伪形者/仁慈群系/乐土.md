# 乐土



作者：帝国外务部大主教

”乐土“是一种生态环境的代称——由复苏菌种所塑造的环境——菌群将会以极快的代谢速率生长、覆盖、代谢、催化生态环境的翻新，形成一种整体的特殊生态循环加快。并且还会生成特别的信息素诱导物种迁徙以填补生态空缺。在这加快的循环当中原本被破坏的环境便能被复原。
