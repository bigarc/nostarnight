# 魔法之神-墨托斯

![封面](https://oss.matrees.cn/prod/definitionCover/2049747958802894848.jpg)

作者：帝国外务部大主教

墨托斯·逻各斯，魔法之神、吟游诗人之神、大贤者、第一位学者、第一位魔法师、第一位吟游诗人。神明意象为翻开的卷籍、书写宇宙理性与规律的羽毛笔、宁静的吟游诗人与晨曦的求知之光。 他是学者——一位永远伏案于夜空之下的学者，将沉思之梦与求索光芒化作可见的漫天星辰 他是吟游诗人精神的终极体现——并非依靠华丽的辞藻或机巧的辩才，而是以深邃的智慧与永恒的真诚作为最动人的乐章。是所有那些油嘴滑舌吟游诗人所追求的、超越技艺的崇高境界。 他是晨曦之光——那是在经历整个黑夜的孤寂求索后，真理终于如朝阳般刺破黑暗的刹那。 所以熬夜写书到天亮自古有之
