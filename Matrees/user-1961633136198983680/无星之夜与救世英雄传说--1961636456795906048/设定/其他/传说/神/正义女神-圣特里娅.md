# 正义女神-圣特里娅

![封面](https://oss.matrees.cn/prod/definitionCover/2049746979789426688.jpg)

作者：帝国外务部大主教

圣特里娅·尤列米娜 是胜利、牺牲、慈悲的三相女神、同时还是战争之神、正义之神、火焰之神、大天使，意象亦有三重：洁白的羽翼与半融桂冠昭示她的胜利，破碎的长剑与圣洁手骨铭记她的牺牲，绕剑的荆棘与熔金泪痕见证她的慈悲。
