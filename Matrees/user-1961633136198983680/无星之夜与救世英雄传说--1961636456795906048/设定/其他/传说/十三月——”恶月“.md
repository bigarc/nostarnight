# 十三月——”恶月“



作者：帝国外务部大主教

对于绝大多数凡人而言，“恶月”只是一个传说中的概念，仅仅年末才会在日历边缘出现的、短暂十几天的“闰日”。他们完全无法感知这个真实存在的、无比漫长的 79, 671天。 在恶月中使用的是真正的环绕年——”世界“环绕“太阳”一圈的时间，现代的1300年才相当于7个环绕年，也就是创世的七天。 只有那些触摸到世界本源的存在——强大的法师、真神的牧师、传奇冒险者、或是某些古老生物——才能主动进入、或被意外卷入真正的、缺失的、被隐去的“恶月”。 “恶月”可以是 “里世界”、“时间的缝隙” 或 “规则的试验场”，与幽影界密不可分。在这里，物理和魔法规则都可能变得扭曲。
