# 云龙



作者：帝国外务部大主教

也被成为凤凰、不死鸟、亦或天使。 温和状态是白色的气态的不定形体，巡行天际时宛若悠长云旋，又如展开的羽翼与飘逸的翎尾，空灵静谧，呈现流畅的“游动”姿态。 燃烧状态则是带火花与闪电的低鸣风暴。在由温和转向这状态的过程中，云龙会先低空飞速盘旋，体内的“不稳定气体”会先沸腾，出现火花与电光。猛然抬升间，火焰从头部扩张，庞大的身躯会一瞬间爆燃，化作咆哮的火焰风暴、奔走的龙卷之形。
