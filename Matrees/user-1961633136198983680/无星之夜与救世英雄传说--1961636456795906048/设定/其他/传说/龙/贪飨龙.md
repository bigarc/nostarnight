# 贪飨龙



作者：帝国外务部大主教

从龙神身上出芽的活性血肉，他们是贪婪的掠食者，不休的追猎者，辛勤耕耘者；他们于空间之中贪食，在天空中啃食出的裂隙就像是在冰块中钻出的玻璃洞；又像是蚯蚓在泥中松土的啃穴。 他们的身躯由层层叠叠外翻的尖牙与锐骨组成，扭曲成一个不休螺旋的畸形野兽：他们的血肉不定性，可以幻化出羽翼，也可以延展出利爪，他们有已有的百兽之形，也有未诞生的胎中之貌。 他们似乎与重塑教派关系密切，由其提供的记录与传说，存在被训的温和猎兽。 但古龙已灭绝，这些我毫无印象的龙种又是从哪里冒出来的？龙神又是哪一位神明的披挂？
