# 森王龙



作者：帝国外务部大主教

生命界垂直树海中的顶级掠食者，瑰丽自然生态与狂野原始生命的象征，永不停息的心脏与永远奔腾的沸血，拥有着一切掠食者杂糅的优点，分能够飞行的雌性与更加强壮的雄性，又被称为执政官、帝王龙或者帝皇龙
