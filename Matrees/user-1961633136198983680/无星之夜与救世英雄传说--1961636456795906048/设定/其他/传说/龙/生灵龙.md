# 生灵龙



作者：帝国外务部大主教

在灵云族群的集体传说中，“生灵龙”被视为所有灵云亚种（悦灵云、恶灵云、温灵云等）的起源与理想聚合形态。其形象被描述为一种宏伟而宁静的龙形白色云气（也许和云龙十分相似）——聚合了灵云们各异的七彩之色，洁白的身体又是最甜蜜、完全不会腻的白色美味霜糖。慢悠悠飘荡出来的彩虹霞光还能让人迸发心中感情，无论是喜是悲地去放声无所顾虑——鉴于描述来自悦灵云，所以仅供参考。 学者认为，“生灵龙”可能并非一个实体生物，而是灵云族群对自身集体潜意识、起源记忆或理想共生状态的一种神话投射。尚无确凿证据证明“生灵龙”是一个独立存在的古代生命。
