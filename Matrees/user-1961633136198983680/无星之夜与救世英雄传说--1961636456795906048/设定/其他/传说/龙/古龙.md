# 古龙



作者：帝国外务部大主教

被广泛认知，也就是现在所俗称的“古龙”，其实指的是曾今的“兽之龙”，其遗辽便是现今的飞龙、土龙、火龙等等次一等的龙种。 广义的龙，则是一种文化符号与力量等级的标签。它被用来尊称那些同样古老、强大，在生态或神秘学上占据类似“顶点”地位的其他大魔兽。这些存在或许形态、本源与“兽之龙”迥异，但因其实力与传奇性，在人们的敬畏与口传中，亦被冠以“X龙”的称谓。 纯粹的古龙直接被称呼为古龙，而现代龙则根据血脉，又划分为古代种、纯血种、混血种、异种龙。
