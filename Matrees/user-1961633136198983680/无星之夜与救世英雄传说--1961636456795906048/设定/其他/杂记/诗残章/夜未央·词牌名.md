# 夜未央·词牌名



作者：帝国外务部大主教

句式：上下各一句，或残句合一。 叠句（XXX，XXX。）对句（XXXXX，XXXXX。）。 上阕与下阕须表意对反，而又顺承无暇。 叠句末字与对句末字须押同韵。上阕与下阕可换韵亦可同韵，视立意更替而定。 押平声韵者多述景叙事、从容铺陈；押仄声韵者多抒慨寄哀、沉郁顿挫。 押韵以叠句末字定调，五言句末字呼应，一韵贯通全阕为佳。
