# 《人类种考古溯源汇总》——亚里斯·莎拉·伊德琳



作者：帝国外务部大主教

文章内容仅作参考 伊德琳提出了一个颠覆性的可能——人类、精灵、矮人、兽人、同出一源——本来这一点不必多提，但伊德琳疯狂地将时间点延后到了黑铁战争之间。 一般来说，学者们普遍认为人类种的分化完成于黄金时代，城邦的形成便是人种分化的完成。 伊德琳则认为，人类种的分化开始于黑铁时代，因为环境巨变与战争才导致人类种分裂与在生理上的彻底分化。 这代表着一切关于白银时代的推论都将被彻底推翻，人类种之间的关系将要发生翻天覆地的变化。 但同时这一观点还能解决诸多历史疑案，同时也由于战争的断代，我们还无法彻底确认哪一种学说是正确的——伊德琳甚至因此受到了精灵的几次追杀——都是因为伊德琳当面当众激怒了那位老学者
