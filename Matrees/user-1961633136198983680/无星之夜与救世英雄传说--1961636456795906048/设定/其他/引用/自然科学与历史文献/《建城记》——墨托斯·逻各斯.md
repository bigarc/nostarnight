# 《建城记》——墨托斯·逻各斯



作者：帝国外务部大主教

——据传为贤者墨托斯·逻各斯于神代末期所作的通俗纪事，文风平实，因年代久远，现存多为断章残篇。 本书被后世学者视为一部珍贵的古代社会志，生动描绘了奥瑟里斯安、奥里哈鲁根、奥库利维斯等不同城邦族群从部落聚落走向国家雏形的社会变迁。 墨托斯·逻各斯以惊人的同理心，捕捉了时代洪流中普通人的情感变迁：对故土的眷恋、对新事物的恐惧与向往、不同习俗的碰撞与融合、以及在集体生活中个人身份的重新定位。 其笔下的奥瑟里斯安农人、奥里哈鲁根匠师与奥库利维斯学者，虽习俗各异，却在时代洪流中展现出了相通的人性光辉。
