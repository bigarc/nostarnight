# 《家喻户晓》——莫拉·因奈特



作者：帝国外务部大主教

本书为传奇吟游诗人莫拉·因奈特游历四方所著的通俗博物著作，系统记述了白银时代中期各地区的风物、民俗与传说。其在流传过程中衍生出多个版本，其中以改编童话故事集《家喻户晓》最为“家喻户晓”。
