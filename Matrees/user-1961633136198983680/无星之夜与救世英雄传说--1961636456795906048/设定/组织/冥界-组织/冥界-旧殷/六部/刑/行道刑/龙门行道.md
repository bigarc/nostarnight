# 龙门行道



作者：帝国外务部大主教

龙门这一关城的行道。龙门是重要的关口，是鬼门——龙门——玉门三门的中间位置，向外是军事区域，向内是农垦拓荒，此地行道还肩负着审查间敌、督审违禁的任务
